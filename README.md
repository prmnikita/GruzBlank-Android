# Грузовой бланк (Android)

Приложение для оформления отправки груза без логотипа и интернета.

## Возможности
- Необязательный номер бланка, ручной ввод
- Город, назначение, получатель, отправитель
- Любое количество грузовых мест: для каждого наименование, вес, длина, ширина и высота
- Расчёт общей кубатуры в м³ (габариты в сантиметрах) и общего веса
- PDF на кириллице, сохранение в «Загрузки/GruzBlank»
- Отправка последнего PDF через стандартное меню Android
- Автоматическое сохранение черновика

## Сборка APK без компьютера
1. Откройте вкладку [Actions](https://github.com/prmnikita/GruzBlank-Android/actions).
2. Откройте **Build Android APK** и последний запуск.
3. Если сборка успешна (зелёная галочка), скачайте артефакт **GruzBlank-debug-apk**.
4. Распакуйте ZIP на телефоне, установите `app-debug.apk`.
5. Проверьте создание PDF с несколькими грузовыми местами.

При ошибке сборки откройте логи шага `gradle assembleDebug --stacktrace` и передайте сообщение об ошибке для исправления.

## Ограничения
Это первоначальная тестовая версия, не опубликованная в Google Play. Требуется реальное тестирование APK на Android 10 или новее. История PDF пока не реализована; отправить можно последний созданный документ, предыдущие доступны в файловом менеджере.
